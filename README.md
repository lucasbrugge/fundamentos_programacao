# Fundamentos de Programação

Repositório criado para registrar minha evolução nos fundamentos de programação durante a graduação em **Tecnologia em Sistemas para Internet — UTFPR**.

Aqui ficam exercícios, atividades, exemplos e anotações desenvolvidos ao longo da disciplina, utilizando principalmente **TypeScript**.
