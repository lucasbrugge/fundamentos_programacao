# Fundamentos de Programação

Repositório para registrar minha evolução na disciplina de Fundamentos de Programação do curso de
**Tecnologia em Sistemas para Internet — UTFPR**, utilizando **TypeScript**.

Aqui ficam exercícios, exemplos e anotações desenvolvidos ao longo das aulas.

## Conteúdos

1. [Instruções simples e tipos primitivos](01-instrucoes-simples-e-tipos-primitivos/)
2. [Programação orientada a objetos](02-programacao-orientada-a-objetos/)
3. [Estruturas condicionais](03-estruturas-condicionais/)
4. [Estruturas de repetição](04-estruturas-de-repeticao/)

## Organização

Os conteúdos seguem a sequência das aulas. Cada assunto reúne suas listas e exercícios.

```text
.material-do-professor/                  # PDFs, slides e exemplos do professor
01-instrucoes-simples-e-tipos-primitivos/
├── lista-b2/
│   ├── atividade.md                     # Enunciado geral da lista
│   ├── exercicio-01/
│   │   └── index.ts                     # Enunciado comentado e implementação
│   └── ...
└── lista-b3/
02-programacao-orientada-a-objetos/
├── lista-c1/
│   └── atividade.md                     # Enunciados e respostas de conceitos
└── lista-c3/
03-estruturas-condicionais/
├── lista-d2/
└── lista-d4/
    └── exercicios-05-06/                # Conversão para algarismos romanos
04-estruturas-de-repeticao/
├── lista-e2/
│   ├── atividade.md
│   └── index.ts                         # Etapas da classe PainelContador
└── lista-e4/
    ├── atividade.md
    └── index.ts                         # Etapas da classe InteiroMatematico
```

Os arquivos `atividade.md` reúnem as orientações e os enunciados de cada lista.
Os exercícios independentes têm sua própria pasta, com um `index.ts` para desenvolver a solução.
Os materiais do professor ficam disponíveis para consulta em `.material-do-professor/`.

## Aprendizado

Este repositório é um espaço para aprender, praticar, testar ideias e acompanhar
minha evolução na programação. Os arquivos Markdown também funcionam como um
caderno de estudos para registrar conceitos, dúvidas e aprendizados.

O objetivo é construir uma base sólida para conteúdos mais avançados, resolvendo
os exercícios e entendendo os resultados de cada tentativa.

> **Aprender → praticar → testar → errar → entender → melhorar.**
